# AI/R Fellowship Bootcamp — AWS, TypeScript & Fullstack

Bem-vindo ao repositório de documentação, anotações e códigos práticos desenvolvidos durante o **Bootcamp AI/R Fellowship (Compass UOL)**.

Este espaço foi estruturado para registrar o progresso diário, consolidação de conceitos teóricos, resolução de exercícios e o desenvolvimento de entregáveis das Sprints do programa.
