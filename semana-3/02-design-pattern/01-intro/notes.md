# Introdução

Design Patterns (Padrões de Projeto) são soluções reutilizáveis para problemas recorrentes no desenvolvimento de software.

Eles não são códigos prontos ou regras que devem ser seguidas obrigatoriamente. São modelos de organização e estruturação que ajudam a definir como classes, objetos e responsabilidades podem se relacionar para resolver determinados problemas.

O objetivo deste estudo é compreender os principais Design Patterns e, principalmente, entender **qual problema cada padrão resolve, como ele funciona e em quais situações pode ser utilizado**.

Os exemplos deste diretório serão implementados utilizando **TypeScript**, buscando relacionar os padrões estudados com conceitos já vistos durante o bootcamp, como:

- Classes e objetos
- Interfaces
- Encapsulamento
- Herança
- Polimorfismo
- Composição
- Abstração

> O foco não é decorar padrões, mas desenvolver a capacidade de reconhecer problemas de projeto e compreender diferentes formas de solucioná-los.
